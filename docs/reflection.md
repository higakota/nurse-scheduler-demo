# 開発を通じて学んだこと

使用者への確認が十分でないまま開発を進めると、想定と異なる機能ができ、確認と修正を繰り返すことがありました。また、勤務表の条件が複雑で、実現したいことを整理してAIへ言葉で伝える難しさも感じました。

この経験から、業務を効率化するには、まず使用者の仕事の進め方や判断基準を理解することが大切だと学びました。聞き取った条件を具体的な例で確かめ、認識を合わせてから開発を進める必要があると感じました。

AIは実装を支援できますが、必要な機能や使いやすさの判断は人が担う必要があります。使用者に実際に操作してもらい、反応を確認しながら細かく調整する重要性を実感しました。

また、不具合が起きる操作を再現して原因を確かめ、修正後はほかの機能への影響も確認する大切さを学びました。バックアップや更新方法の整備にも取り組み、使用者が継続して安心して使える状態まで考えることが、システム開発では重要だと感じました。
