# 聞き取った勤務表の作成条件

## 毎月の作成が大変だった理由

使用者は、医師の出勤予定、看護師・検査技師の人数、勤務希望、会議、公休日数などの複雑な条件を確認しながら、毎月の勤務表を作っていました。条件を同時に満たすように調整する作業に、手間と時間がかかっていたことが開発の出発点です。

例えば、医師が増えれば診察室に必要な看護師も増えます。会議に出る人はその時間帯の診療人数には数えられず、検査室では人数だけでなく職種も考える必要があります。ある日の休みを動かすと、別の日の不足や連勤、公休日数にも影響します。

このため、聞き取りでは「何人いるか」だけでなく、**誰が・いつ・どの業務を担当できるか、何を変更してよいか**を確認しました。作業時間の具体的な削減率はまだ測定していません。

## 使用者に確認した内容

| 確認したこと | 聞き取った内容・アプリでの扱い |
|---|---|
| 作成の単位 | 毎月の勤務表を作る。午前と午後で、医師予定や勤務可能な人が変わる |
| 職種・勤務区分 | 看護師と検査技師、常勤と非常勤がいる。非常勤の週上限は個人ごとに設定する |
| 必要な人数 | 受付・診察室・検査室を分け、医師予定をもとに午前・午後の必要人数を確認する |
| 休み・休暇 | 希望休・有給・夏季休暇を区別する。全日だけでなく半日単位の入力や、公休と有給の組み合わせがある |
| 会議 | 日程と参加者を指定する。会議は勤務だが、その時間帯の診療人数には含めない |
| 外部の応援 | 事前に来られる人と、不足を見て依頼した人を分ける。依頼はアプリ外で行い、来院が決まった予定だけ登録する |
| 他施設への支援 | 通常の勤務として勤務日数・連勤に数えるが、自院の診療人数には含めない |
| 変更時の確認 | 休みの出勤変更には本人の了承が必要。依頼済みの応援や希望休を、自動で勝手に動かさない |
| 出力 | 勤務と希望を見比べ、月間表として印刷できるようにする |

以下は使用者の業務について確認した条件です。すべての医療機関に共通するルールではありません。職員名・施設名・医師名・実際の勤務表は公開しません。

## 配置に必要な人数と職種

診療のある午前・午後それぞれについて、次の最低人数を確認します。同じ人を、同じ時間帯の複数の配置へ重複して数えません。

| 配置 | 必要な条件 |
|---|---|
| A：受付 | 看護師が最低2人必要 |
| B：診察室 | **診療担当の医師1人につき、看護師1人が必要** |
| C：検査室 | 医師が3人以上の時間帯は最低2人。それ以外は予約状況などを見て、使用者が1人または2人を指定する |
| 診療側全体 | 午前・午後それぞれにベテラン看護師が最低1人必要。上記の看護師の内数であり、配置先ごとに追加1人という意味ではない |
| 検査技師 | 検査室を担当する。登録されていても、その時間帯に来院・勤務できなければ人数に数えない |

検査室に2人必要な場合は、**検査技師＋看護師でも、検査技師＋検査技師でもよい**という条件を確認しました。検査技師が不在の時間帯は、まず他施設の検査技師の応援を検討し、看護師だけで担当するのは明示的に選ぶ最終手段です。

### 人数の考え方の例

会議や休みなどがない場合の、最低配置の例です。診療側にはベテラン看護師も含める必要があります。

| 医師予定と検査室 | 受付 | 診察室 | 検査室 | 最低人数の例 |
|---|---|---|---|---|
| 医師2人、検査室1人 | 看護師2人 | 看護師2人 | 検査技師1人 | 看護師4人＋検査技師1人 |
| 医師3人、検査室2人 | 看護師2人 | 看護師3人 | 検査技師2人 | 看護師5人＋検査技師2人 |
| 医師3人、検査室2人 | 看護師2人 | 看護師3人 | 検査技師1人＋看護師1人 | 看護師6人＋検査技師1人 |

同じ合計人数でも、職種や担当可能な範囲が違えば配置できません。[職種の扱いを修正した事例](case-studies.md#2-検査室の人数と職種を正しく数える)

## 休み・連勤・会議も同時に確認する

- 希望休・有給は全日・午前・午後を区別する。希望休と会議が重なった場合は休みを優先し、警告して見直しを促す。
- 常勤は、スタッフごと・月ごとに指定した公休日数と一致させる。非常勤は個人ごとの週勤務上限を守る。
- 夏季休暇は勤務せず、公休にも有給にも数えない。公休と有給などを午前・午後で組み合わせる場合も区別する。
- 通常の全日勤務は原則5連勤以内とし、不足時は応援を先に検討する。条件上必須のケースや明示した最終案の6連勤は区別し、全日勤務の7連勤以上は禁止する。
- 半日勤務や全日有給は全日勤務の連勤をリセットする。月をまたぐ連勤は前月末の勤務も含めて確認する。
- 会議は勤務として数えるが、参加者はその時間帯の診療配置には数えない。ベテランが会議に出る場合も、診療側に別のベテランが必要になる。
- 日曜・祝日は休診。金曜午後も診療はなく、会議が入る場合がある。年末年始の休診日は年ごとに設定する。

## 条件を満たせないとき

希望休や勤務条件を黙って緩めず、不足する日付・午前午後・職種・人数を確認できるようにします。使用者が応援を相談し、来院予定を登録してから反映します。本人了承の出勤や代わりの休みへの変更も、内容を確認して保存します。

探索が時間内に終わらない場合と、条件を満たせないことが分かった場合は区別します。最適解やすべての入力での成立を保証するものではなく、完成した表は使用者が最終確認します。
