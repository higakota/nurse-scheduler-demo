# 成果画像

架空データを使った、実際のアプリ画面と印刷用の表示です。3枚とも1912×1036ピクセルにそろえています。勤務表は画面部分を抜き出し、全体が収まるよう表示倍率を調整しています。

## ホーム画面

対象月と、入力・不足確認・応援登録・勤務表を開く手順を一つの画面にまとめています。

![ホーム画面](screenshots/home.png)

[画像を開く](screenshots/home.png)

## 作成した勤務表と希望の比較

上段の実際の勤務と、下段の希望休・有給を比較できます。依頼した応援の配置や、午前・午後の不足も同じ表で確認できます。

![作成した勤務表](screenshots/roster.png)

[画像を開く](screenshots/roster.png)

## 印刷用の勤務表

希望休・有給を色で区別し、勤務と上下に並べています。依頼後に来院が決まった応援は印刷時にまとめて表示します。画像にはサンプルの下書き・未確定の表示も含めています。

![印刷用勤務表](screenshots/print.png)
