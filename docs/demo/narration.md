# ナレーション台本

日本語合成音声（Nanami）を使用しています。時刻は公開動画に対応します。

**0:02** 勤務表作成の操作を紹介します。入力から保存、不足の確認、ヘルプの登録、印刷まで進めます。

**0:13** まずスタッフを確認します。看護師、検査技師、勤務区分、ヘルプを分けて登録します。

**0:24** スタッフを確認したらホームに戻ります。作成する対象月を選び、切替を押します。

**0:41** 対象月を切り替えました。ホームの今月の入力から、医師予定を開きます。

**0:49** 対象月を確認して、サンプルのエクセルを選びます。読み込んだ後も、最後の保存まで進めてください。

**1:00** 対象月と同じシートを選び、医師、休診日、会議の候補を読み取ります。

**1:10** 午前と午後の担当医を、元のエクセルと照合します。個別確認のある日にチェックを入れます。

**1:23** 残りの確認操作は短く進めます。実際には、すべての候補を照合してください。

**1:34** 最後に変更内容の確認チェックを入れ、医師予定を保存するボタンを押します。

**1:44** 医師予定を保存しました。完了の表示を確認します。

**1:53** スタッフと日付のマスを押して入力します。今回は、検査スタッフの全日希望休を登録します。

**2:20** 希望休を保存しました。完了の表示を確認します。

**2:27** 常勤の休日日数と、非常勤の週上限を確認して保存します。

**2:37** 休日日数と週上限を保存しました。

**2:44** 日曜や祝日などの休診日を確認します。変更した場合も、保存を忘れずに行います。

**2:54** 休診日を保存しました。

**3:00** 会議名を開いて、名称を変更する例です。参加者を変更したときも、最後に保存します。

**3:17** 会議の変更を保存しました。

**3:23** 依頼前から来られる日が決まっているヘルプを入力します。日付と時間帯を選んで保存します。

**3:41** 事前ヘルプの勤務可能日を保存しました。

**3:49** 医師予定と検査室の必要人数を確認し、下の保存ボタンを押します。

**3:59** 必要人数を保存しました。

**4:07** 月をまたぐ連続勤務の確認に使います。初回は直前六日分を入力し、保存します。

**4:17** 前月末勤務を保存しました。上の手順バーから、不足の確認へ進みます。

**4:41** 事前のヘルプも使って、仮の勤務表を作ります。表の中の勤務を確認しましょう。

**4:50** 表の下には不足する職種と人数が出ます。この例は十一月九日に検査技師が不足します。ほかの施設への相談はアプリの外で行います。

**5:17** 来院が決まったヘルプの登録へ進みます。人を選び、カレンダーで不足と来院予定を確認します。

**5:31** 来院する日と時間帯を入力しました。まだ未保存です。登録したヘルプを反映するボタンで、登録と勤務表の更新へ進みます。

**5:48** ヘルプを登録すると、勤務表の変更確認が開きます。変更内容を見て、確認のチェックを入れ、勤務表を保存します。

**6:16** 更新した勤務表を保存しました。登録したヘルプも配置されています。

**6:33** 希望休と有給との比較を表示します。上の勤務と下の希望を見比べて、変更漏れがないか確認します。

**7:04** 勤務表は印刷や、ピー・ディー・エフ保存もできます。入力した後は保存を確認し、同じ表を更新しながら仕上げます。
