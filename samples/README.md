| 項目 | 内容 |
|---|---|
| 対象月・シート名 | 2026年11月・「11月」 |
| 日付 | 4行目。Excelの日付値として格納 |
| 曜日 | 5行目 |
| 医師予定 | 6行目。左が午前、右が午後の入力例 |
| 会議欄 | 7行目。会議の自動取込を保証する見本ではない |
| 職員 | 架空の9人 |
| 希望欄 | 各職員の下段。希望休・半日希望・有給の見本 |
| 書式 | 曜日表示、罫線、希望欄の色分け、固定見出し |

## 試す

1. アプリを起動し、対象月を2026年11月にする。
2. 「医師予定」でこのファイルを選び、「11月」を読み取る。
3. 確認画面で午前・午後の医師を確認して保存する。

この取込は医師予定を中心とするものです。職員の希望欄をすべて自動で読み取る機能ではありません。初回起動時の架空DBに、同じ希望・会議・休日を登録しています。

勤務欄は空欄の入力見本です。完成済み勤務表を表していません。診療日を8日に絞った簡略例で、実際の施設の休日・必要人数を示しません。氏名・施設・日付の予定はすべて新規に作成した架空のものです。
