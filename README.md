# 看護職員の勤務表作成支援アプリ

現場の利用者への聞き取りをもとに、月ごとの勤務希望・必要人数・他施設からの応援を整理し、勤務表の作成と修正を支援するWebアプリです。

**このリポジトリでは、架空データを使ったサンプル環境を提供しています。人名・施設名・日程・Excelはすべて架空で、実際の職員や勤務データは含めていません。** 実用版のGit履歴・データベース・バックアップ・元のExcelは引き継いでいません。実在する人物の情報を入力しないでください。

![架空データのホーム画面](docs/screenshots/home.png)

## できること

- Excelから医師予定を読み取り、確認・修正して保存
- 希望休・有給・会議・非常勤の週上限を登録
- 勤務表を自動作成し、人員不足を確認
- 来院可能な応援スタッフを反映し、変更内容を確認
- 保存済み勤務表の編集、希望との比較、カラー印刷
- バックアップと復元、前月勤務の引き継ぎ

## 動かす（Python 3.13）

Windows PowerShellで、このフォルダを開いて実行します。

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe demo_run.py
```

ブラウザで http://127.0.0.1:5001/?month=2026-11 を開きます。実用版のポート5000とは分かれています。初回は架空データが自動で入り、変更はこのフォルダ内の `instance/demo.sqlite3` に保存します。終了は起動した端末で Ctrl+C です。Mac/Linuxでは `python3 -m venv .venv` と `.venv/bin/python` を使います。

サンプルは短時間で操作を試せるよう、診療日を8日に絞った簡略例です。休日数もこの架空の条件に合わせており、実際の施設の条件を表していません。

## 3分で試す

1. **2026年11月**のホームを開き、スタッフと登録済みの希望を確認します。
2. 「事前登録のヘルプも使って仮作成」で勤務表を作成し、不足を確認します。
3. 編集画面で勤務・希望との比較を確認し、印刷プレビューを開きます。
4. Excel取込を試す場合は `samples/sample_requests_2026-11.xlsx` の「11月」シートを選択します。読み取り後の確認画面では、保存前に日付・担当医を確認してください。既存の医師予定を置き換える操作なので、必要なら別途バックアップします。

サンプルExcelは取り込み形式を確認するための新規作成ファイルです。実際の職場のExcelのコピーではありません。サンプルの休日はデモデータ側で設定しています。月が変わっても休日が自動で全件登録されるわけではありません。

## 設計と検証

Python / Flask / SQLite、HTML / CSS / JavaScriptで構成しています。外部へのメール送信は行いません。制約に従って配置を探索し、結果は別の検証処理でも確認します。勤務表の版と入力条件の変更を検出し、古い結果の上書きを防ぐ設計です。

```powershell
.\.venv\Scripts\python.exe -B -m unittest discover -s tests
```

テストは仮名・一時DBを使用します。実運用の正しさや全入力での最適解を保証するものではありません。勤務表の最終判断は利用者が行います。

## 開発で取り組んだこと

利用者の操作をもとに、勤務希望と会議の優先関係、半日勤務、依頼済み応援の固定、変更後の連勤確認などを整理し、機能と導線を改善しました。説明用の構成図と振り返りは [開発メモ](docs/portfolio.md) に記載しています。

開発には生成AIを利用しています。設計上の判断や検証内容は [開発の振り返り](docs/development-review.md) で整理します。
